# 구조 정리

## 런타임

브라우저/Next.js는 `web/public/data/*.json`만 읽습니다. 루트 `data/`와 `src/`는 데이터 재생성 도구이며 Vercel 요청 처리 시 사용하지 않습니다.

## 자연어 추천

`/api/chat-recommend`는 다음 순서로 동작합니다.

1. 자연어에서 맵기·국물·날것·주재료·월 및 부정 표현을 규칙으로 파싱
2. 지역 포함/제외 조건과 실제 식당 보유 여부로 후보 제한
3. 현재 월 기준 제철 후보와 취향 점수로 로컬 후보 정렬
4. 외부 LLM 연결 시 후보 데이터만 전달하고 최대 5개 ID 선택
5. 동일 식재료가 과도하게 반복되지 않도록 최종 다양성 보정
6. LLM 실패 시 로컬 결과 반환

## 카테고리 추천

취향 점수(100점) + 제철 보너스(12/3/0)를 계산합니다. 날것/익힘·주재료·국물을 만족하는 정상 추천을 먼저 채우고 부족한 자리만 대체 추천으로 채웁니다.
